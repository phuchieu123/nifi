Sự miêu tả:

Nhiệm vụ báo cáo: báo cáo số liệu cho máy chủ Ganglia. Các số liệu sau được báo cáo:

  • FlowFiles Trong (5 phút): The number of FlowFiles received via Site-to-Site in the last 5 minutes
  • Byte trong (5 phút): The number of bytes received via Site-to-Site in the last 5 minutes
  • FlowFiles Out (5 phút): The number of FlowFiles pulled from Output Ports via Site-to-Site in the last 5 minutes
  • Byte ra (5 phút): The number of bytes pulled from Output Ports via Site-to-Site in the last 5 minutes
  • Số byte đã đọc (5 phút): The number of bytes read from disk by NiFi in the last 5 minutes
  • Số byte đã viết (5 phút): The number of bytes written to disk by NiFi in the last 5 minutes
  • Các FlowFiles xếp hàng: The total number of FlowFiles currently queued on the system at the point in time at which the Reporting Task is run
  • Các byte xếp hàng: The total number of bytes allocated by the FlowFiles that are currently queued on the system at the point in time at which the Reporting Task is run
  • Chủ đề hoạt động: The number of threads actively running at the point in time at which the Reporting Task is run
